# Security Policy

We take security issues seriously. Thank you for responsibly disclosing vulnerabilities.

## Reporting a vulnerability

Preferred: send an email to `starletprachi10@gmail.com` (replace with a real contact).

If you cannot share details via email, open a private issue labeled `security`.

## What to include

- A clear summary of the issue.
- Steps to reproduce and PoC (if available).
- Impact assessment (data exposure, remote code execution, etc.).
- Your contact information and preferred disclosure timeline.

## Response process

We will acknowledge receipt within 7 days and aim to provide a remediation timeline.

## Sensitive data

Do not send passwords, private keys, or full database dumps via email. Provide only the minimum data required to reproduce the issue.
