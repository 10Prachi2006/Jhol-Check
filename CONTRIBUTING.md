# Contributing to Jhol-Check

Thanks for your interest in contributing! Contributions are welcome via issues and pull requests.

## How to contribute

- File an issue to discuss large changes or features before implementing.
- Fork the repo and create a feature branch: `git checkout -b feature/your-change`.
- Keep changes small and focused; open a single PR per feature or fix.

## Development setup

1. Install Python 3.10+.
2. Create and activate a virtual environment.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

## Code style

- Follow existing project style. Recommended tools: `black`, `isort`, and `flake8`.
- Run formatters before opening a PR.

## Tests

- Add tests under an appropriate directory and ensure `pytest` passes locally.

## Pull requests

- Target the `main` branch (or open a PR against the branch named in the issue).
- Provide a clear description of what the PR changes and why.
- Link to related issues and include reproducible steps or minimal examples when applicable.

## Communication

- For security-sensitive issues, see `SECURITY.md` for responsible disclosure.

Thank you — your contributions help make Jhol-Check better!
